# CURIOSITY-EVA · Vista desde el casco

Prototipo web de un traje EVA para Marte con asistente HoloConnect AI.

## Archivos
- `index.html`: estructura y textos fijos de la página.
- `config.js`: **datos editables** (paisaje, marcadores, escenarios, pasos).
- `style.css`: colores y diseño del visor y los paneles.
- `app.js`: lógica. No hace falta tocarla para cambiar datos.

## Publicar en GitHub Pages
1. Sube estos 4 archivos a un repositorio nuevo.
2. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
3. Tu sitio queda en https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/

## Probar en tu computadora
Abre `index.html` con doble clic, o usa la extensión Live Server de VS Code.
